# Architecture Decision Records

Create one file per material decision, for example 0001-shared-catalog.md.

Template:

# ADR-NNNN: Decision title
- Status: Proposed | Accepted | Superseded
- Date:
- Decision owner:

## Context
Problem and constraints.

## Decision
Specific choice.

## Alternatives considered
Plausible options and reasons for rejection.

## Consequences
Benefits, trade-offs, costs, and risks.

## Revisit triggers
Evidence that would justify reconsidering the decision.

Use ADRs for choices affecting architecture, data, security, deployment, cost, or compatibility.
